# Contributing

How to contribute
1. Fork the repository and create a feature branch: feature/short-description
2. Write tests for new behavior
3. Ensure linting and formatting pass
4. Submit a pull request describing the change and rationale

Branching model
- main: production-ready code
- work_here: current development branch
- feature/*: for new features

Code style
- Follow Python PEP 8 guidelines
- Use meaningful variable and function names
- Keep commits small and focused
- Use descriptive commit messages

Reporting bugs
- Provide steps to reproduce, expected vs actual behavior, and environment details.
