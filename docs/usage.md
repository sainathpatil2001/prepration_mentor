# Usage

Users & roles
- Admin: manages users, config, and global settings
- Instructor: creates exams, questions, and grades submissions
- Student: takes exams and views results

Common workflows

Instructor
1. Create a question bank (MCQ, True/False, Essay)
2. Create an exam: set duration, start/end times, randomization, pass marks
3. Assign exam to a course/group
4. Publish exam and monitor live takers
5. Review and grade subjective answers, publish results

Student
1. Login and enroll in a course (if required)
2. Start an available exam (within allowed time)
3. Answer questions and submit before time expires
4. View results and feedback after grading

Admin tasks
- Manage users and roles
- View system logs and metrics
- Run backups and migrations

Tips
- Use staging environment to test new exam settings
- For secure grading, disable copying/paste and consider proctoring integrations
